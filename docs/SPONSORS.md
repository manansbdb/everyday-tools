# GitHub Sponsors (free to enable)

## EN

GitHub Sponsors lets people support you monthly. **Creating a Sponsors profile is free.** GitHub may later ask for identity/tax/payout info so they can pay you — that is normal and not a product fee from us.

### Steps (you must do these in the browser)

1. Open https://github.com/sponsors/manansbdb (or **Settings → Sponsors** while logged in as manansbdb)
2. Complete GitHub’s onboarding (countries/payout methods vary)
3. Tell the Chefe de gabinete when Sponsors is **Active**
4. We then uncomment `github: [manansbdb]` in `.github/FUNDING.yml`

Until then, the Sponsor button may not appear. The app’s in-app donations stay **disabled** until you choose to turn them on.

## PT

O GitHub Sponsors permite apoio mensal. **Criar o perfil de Sponsors é grátis.** O GitHub pode pedir dados de identidade/fiscais/pagamento para te pagar — isso é normal, não é uma taxa nossa.

### Passos (tens de fazer no browser)

1. Abre https://github.com/sponsors/manansbdb (ou **Settings → Sponsors**)
2. Completa o onboarding do GitHub
3. Avisa o Chefe de gabinete quando estiver **Active**
4. Depois descomentamos `github: [manansbdb]` no `.github/FUNDING.yml`

A app mantém doações **desligadas** até tu decideires ligar.
